# Character dataset

A ready-made dataset of **500 well-known people and fictional characters**
(350 real, 150 fictional), each described by **106 Yes/No attributes**.
It was collected from Wikidata and prepared separately (see
`../data_pipeline/DATA.md`); the game only reads the two CSV files below.

## Files

### `characters.csv` — one row per person or character

| Column | Values |
|---|---|
| `name` | Display name, unique |
| 106 attribute columns, e.g. `is_fictional`, `is_male`, `from_europe`, `known_for_music` | `true`, `false` or `unknown` |
| `sitelinks` | Popularity: number of Wikipedia language editions with an article about the entry (26–340) |
| `source` | Wikidata ID and whether the row was reviewed by hand or generated by rules |

```text
name,is_fictional,is_male,is_human,...,sitelinks,source
Albert Einstein,false,true,true,...,322,Wikidata Q937 (CC0); manually reviewed
```

### `questions.csv` — one row per attribute

| Column | Meaning |
|---|---|
| `attribute` | Column name in `characters.csv` |
| `question` | Yes/No question to ask the player |
| `group` | `core` (56 hand-designed questions) or `pool` (51 extra questions) |

Every attribute column of `characters.csv` appears exactly once in
`questions.csv`, in the same order.

## What the values mean

- `true` / `false`: the answer a well-informed player would give.
- `unknown`: the fact is missing or debatable (for example Elon Musk for "Is
  this person from Africa?", or "Is this person still alive?" for a fictional
  character). **Do not treat `unknown` as `false`.** A player is more likely
  to answer "not sure" to these questions.
- Fictional characters: place = country where the original work was created;
  year = year of first appearance.
- Real people: year = birth year; "known for" = what they are mainly famous for.

## Suggested use

- Ask `is_fictional` first ("Is this a fictional character?"): it is known for
  every row and splits the data 150 / 350.
- `sitelinks` can weight how likely each entry is to be chosen. Fictional
  characters have fewer sitelinks (median 47) than real people (median 151),
  so compare popularity within each group.

## Licence and limitations

Facts come from Wikidata (CC0, public domain). The data leans towards the
USA, Europe and men, and generated rows may contain occasional errors.
Facts and popularity reflect October 2026. Details: `../data_pipeline/DATA.md`.
